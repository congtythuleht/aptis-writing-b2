# Aptis Writing B2

Trang luyện viết Aptis Writing (Part 1–4) hướng tới B2: đề mẫu, form mẫu, chấm offline (tô đỏ lỗi, điểm 0–50) và chấm chi tiết bằng Gemini (cần Gemini API key của người dùng, chỉ lưu trên trình duyệt).

Trang là một file `index.html` tĩnh, được build từ dự án gốc bằng `node build.js`.
